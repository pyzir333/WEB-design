Контрольные вопросы по селекторам CSS

1. Какие типы селекторов CSS существуют, и в чем отличие между селектором класса и идентификатора?

Основные типы селекторов CSS:

  • Универсальный селектор (*)
  • Селекторы по тегу (h1, p, div)
  • Селекторы по классу (.classname)
  • Селекторы по идентификатору (#idname)
  • Атрибутные селекторы ([attr=value])
  • Псевдоклассы (:hover, :nth-child)
  • Псевдоэлементы (::before, ::after)
  • Селекторы потомков (div p)
  • Селекторы соседей (h2 + p)

Отличие класса и идентификатора:

Класс (.class) может применяться к нескольким элементам на странице, а идентификатор (#id) должен быть уникальным и применяться только к одному элементу.

2. Как работает универсальный селектор (*), и в каких случаях его использование может быть полезно?

Универсальный селектор (*) применяет стили ко всем элементам на странице.

Полезные случаи использования:

  • Сброс margin и padding для всех элементов
  • Установка box-sizing: border-box для всех элементов
  • Применение базовых стилей шрифта ко всей странице

3. Что такое псевдоклассы и псевдоэлементы? Приведите примеры их использования.

Псевдоклассы - выбирают элементы в определенном состоянии:

  • :hover - при наведении курсора
  • :focus - при фокусе на элементе
  • :nth-child(2) - второй дочерний элемент
  • :first-child - первый дочерний элемент
  • :last-child - последний дочерний элемент

Псевдоэлементы - создают виртуальные элементы:

  • ::before - добавляет контент перед элементом
  • ::after - добавляет контент после элемента
  • ::first-letter - стилизует первую букву текста
  • ::first-line - стилизует первую строку текста

4. Как с помощью атрибутного селектора применить стили к элементам с определенным значением атрибута? Приведите пример.

Атрибутные селекторы выбирают элементы по наличию или значению атрибутов.

Примеры:

  • [href] - все элементы с атрибутом href
  • [href="#"] - элементы с href равным "#"
  • [type="text"] - элементы с type="text"
  • [class~="button"] - элементы с классом содержащим "button"
  • [href^="https"] - элементы с href начинающимся на "https"
  • [href$=".pdf"] - элементы с href заканчивающимся на ".pdf"

5. В чем заключается разница между селектором потомков и селектором соседей? Как они применяются на практике?

Селектор потомков (пробел): выбирает все вложенные элементы независимо от уровня вложенности.

Пример: "div p" выберет все параграфы внутри div на любом уровне вложенности.

Селектор соседей (+): выбирает только следующий соседний элемент того же уровня.

Пример: "h2 + p" выберет только первый параграф, который следует сразу после h2.

Практическое применение:

  • Селектор потомков - для стилизации всех элементов внутри контейнера
  • Селектор соседей - для стилизации элементов, которые следуют сразу после определенных элементов
